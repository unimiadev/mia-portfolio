## About this site

I wanted visitors to see how my work looks on a laptop and a phone, so the project previews use real screenshots inside drawn device frames. Select a project to open its details in place. The little grid in the introduction is interactive, too.

The portfolio itself runs on React, Vite, Tailwind CSS, and Three.js. You can switch between English and Brazilian Portuguese throughout the site, including the résumé downloads.

## Run it locally

With Node.js 22.12 or later installed, run these commands from the repository root.

```sh
npm ci
npm run dev
```

Open the local URL printed by Vite. To try the production version, run `npm run build` followed by `npm run preview`.
